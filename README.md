# Python Programs Collection

A beginner-friendly collection of Python programs covering factorial, Fibonacci numbers, and converting a Python data structure into a dictionary.

## Requirements
- Python 3.9 or newer

## Run
Open a terminal in this folder and run:

```bash
python main.py
```

Choose an option from the menu. The program validates basic user input.

## Topics covered
- Functions and loops
- Input validation
- Factorial calculation
- Fibonacci sequence
- Dictionary conversion using a Python dataclass
